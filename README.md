# ヤフオク 商品非表示

PC版Vivaldi / Chrome向けのManifest V3拡張機能です。

## インストール

1. Vivaldiでアドレス欄に `vivaldi://extensions` と入力します（Chromeは `chrome://extensions`）。
2. 「デベロッパーモード」を有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」を押します。
4. このREADMEと `manifest.json` があるフォルダーを選択します。
5. 開いているヤフーオークションの検索結果を再読み込みします。

フォルダー: `C:\Users\oyasu\Documents\yahoo-auction-extension`

## 使い方

- 検索結果の商品上部の「非表示」で、その商品を一覧から隠します。
- リスト・グリッドの両方に対応し、空白を残さず詰めます。
- 同じオークションIDなら、検索ワード・条件・ページ・表示形式を変えても非表示が続きます。
- 直後は画面下の「元に戻す」で解除できます。
- 後から解除する場合は、検索結果上部の「非表示リスト・解除」、またはブラウザの拡張機能アイコンを使います。
- 管理画面では商品名・IDで絞り込んで個別に解除できます。解除は他の開いているタブにも反映されます。

## 保存と対象範囲

- データは `chrome.storage.local` に保存します。外部サーバーへの送信はありません。
- ブラウザを再起動しても保存されます。拡張機能を削除すると保存内容も削除されます。
- ブラウザ・プロファイルごとに独立し、端末間で同期しません。
- 対象はYahoo!オークションの検索結果領域（`#searchItems`、`#featuredItems`、旧形式の `.Products`）です。
- 下部のおすすめ、スポンサー広告、商品カタログは対象外です。
- 新しいオークションIDでの再出品は別商品です。
- Yahoo側の検索総件数・ページ区切りは変更せず、次ページから商品を補充しません。全商品を隠したページは商品一覧が空になります。
- 読み込みから非表示処理まで、商品が一瞬見える場合があります。
- Yahoo側がHTML構造を変更した場合は修正が必要になる可能性があります。

## 更新

ファイルを更新したら拡張機能の管理画面で再読み込みし、検索結果ページも再読み込みしてください。
